# Integrated Software

ETHOS.FINE integrates and builds on the following software packages:

- **tsam** — Time series aggregation module for energy system models.
  GitHub: [https://github.com/FZJ-IEK3-VSA/tsam](https://github.com/FZJ-IEK3-VSA/tsam)

- **GeoPandas** — extends the datatypes used by pandas to allow spatial operations on geometric types.
  Documentation: [https://geopandas.org/](https://geopandas.org/)
