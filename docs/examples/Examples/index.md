# Modular Examples

The modular examples are a tutorial series for users who have never used ETHOS.FINE before.
Start with the basic tutorial, which builds, optimizes and analyzes a complete small energy system
model in one notebook. The notebooks that follow go through each step and component type in depth.

## Overview
| Example | Description |
|---|---|
| [Basic Tutorial](_00_introduction/_2_basic_tutorial.ipynb) | A two-region electricity system over three investment periods (2020, 2030, 2040) with one example of every component type: sources, sinks, a conversion, a storage and a transmission. A tightening CO<sub>2</sub> limit drives the system from gas power to wind, PV and batteries. **Recommended as starting point.** |
